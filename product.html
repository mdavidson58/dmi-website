Architecture

Plant-local by design, cloud where it helps

Core intelligence runs inside the plant, next to the machines. Analysis keeps working without an Internet connection and sensitive process data stays on site.

  • Edge AI model and process graph run on site
  • Data stays where it's created; DMI queries it in place
  • Suitable for regulated, restricted and remote sites
  • Optional cloud for enterprise management and cross-site reporting
  • Role-based access so each user sees what they need
Where DMI fits

The only platform that runs in the plant and reasons from the process map

Manufacturing AI tools differ on two things: where they run, and how they reason. Most run in the cloud, or start from AI and analytics on tag data. DMI does both differently.

  • DMIRuns on edge nodes inside the plant and follows cause and effect through the process graph.
  • Cloud manufacturing analyticsUnderstand the process, but plant data has to move to their cloud, so cost grows with use.
  • Industrial data and AI platformsCloud data platforms first, with analytics on top.
  • Process analyticsStrong time-series analysis, deployable on premises or in the cloud.
  • Automation-vendor copilotsRun close to the plant, but lead with AI assistants inside one vendor's automation stack.
